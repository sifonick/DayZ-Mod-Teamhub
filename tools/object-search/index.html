Pick objects with the + on each picture, then download them laid out in a line or grid, ready to open in DayZ Editor.

Lay them out

Open the .dze in DayZ Editor with File, Open (put it in your Editor folder, usually Documents\DayZ\Editor). The Object Spawner JSON goes in a server's cfggameplay.json objectSpawnersArr. Heights come from the map's terrain and each object's size, so a few may sit a little high or low: nudge them in the editor.
