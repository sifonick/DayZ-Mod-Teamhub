Extract the entire ZIP to a writable folder. Install DayZ Dedicated Server through Steam and give this account write access to its mpmissions directory. Double-click Start-HeightMaps-4m.bat. The launcher starts a separate password-protected local server for each terrain in turn (port 2452, query port 2455), reads SurfaceY every four metres at cell centres and stops its own server after each completion marker. Keep the launcher open until all three grids say Ready.

The HeightMaps folder beside the launcher will contain PatchAtlas_Chernarus_4m.asc (3840 square), PatchAtlas_Livonia_4m.asc (3200 square) and PatchAtlas_Sakhal_4m.asc (3840 square). Heights are in metres. Row zero is north. Logs and original grids are in HeightMaps/profiles. Rerunning reuses completed exports. To force a fresh run, select a new output folder. Optional batch arguments: -ServerFolder "D:\SteamLibrary\steamapps\common\DayZServer" -OutputFolder "D:\Terrain" -Port 2452.

For your existing web maps open Convert-HeightMap.html in a desktop browser, choose one ASC, select Whole map fills tile 0/0/0 and 256-pixel tiles, then generate the ZIP. Repeat for each terrain. Keep each resulting ZIP under its own map. Use its tile-settings.json for the zoom range and Terrarium decoding. The 4 m spacing is the sampling interval; detail depends on the game's terrain mesh.
