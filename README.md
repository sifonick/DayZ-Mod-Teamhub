# DayZ Map Tile Project

Map assets for DayZ Mod Teamhub.

| Path | Contents |
| --- | --- |
| `maps/atlas/tile-manifest.json` | Map sizes, tile layers, formats and zoom levels. Resolve tile templates relative to this file. |
| `maps/nasdara/elevation/` | Nasdara Terrarium terrain tiles, hillshade PNGs and tile settings. |
| `data/buildings/index.json` | Building datasets for each world. Resolve filenames relative to this index. |
| `assets/model-images/` | Model images organised by the original asset paths. |

See [the atlas guide](maps/atlas/README.md) for tile coordinates and [the building data notes](data/buildings/README.txt) for object coordinates.
